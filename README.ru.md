# Схема положения языка при произношении путунхуа

*[English](README.md) · [简体中文](README.zh-CN.md)*

Интерактивная схема речевого тракта в срединном сагиттальном разрезе. Она показывает положение языка при произношении инициалей, носовых финалей и эризации в путунхуа.

Проект доступен на трёх языках:

- русский: `ru.html`;
- английский: `en.html`;
- упрощённый китайский: `zh-CN.html`.

Код написан на TypeScript. Тексты интерфейса и описания артикуляции хранятся отдельно для каждой локали.

## Структура проекта

```text
index.html                 → корневая страница GitHub Pages, перенаправляет на ru.html
ru.html                    → русская версия
en.html                    → английская версия
zh-CN.html                 → версия на упрощённом китайском
assets/
  style.css                 → общие стили
src/
  types.ts                  → общие типы Point, SoundGroup, AppData и другие
  geometry.ts               → расчёт формы языка и мягкого нёба, без DOM
  engine.ts                 → отрисовка и анимация, без пользовательских текстов
  data.ru.ts                → русские тексты и данные артикуляции
  data.en.ts                → английские тексты и данные артикуляции
  data.zh-CN.ts             → китайские тексты и данные артикуляции
  main.ru.ts                → точка входа русской версии
  main.en.ts                → точка входа английской версии
  main.zh-CN.ts             → точка входа китайской версии
tests/
  unit/                     → тесты геометрии и согласованности данных
  e2e/                      → браузерные тесты Playwright
dist/                       → результат компиляции TypeScript, в репозиторий не добавляется
.github/workflows/          → проверки, тесты и публикация на GitHub Pages
```

`engine.ts` не содержит пользовательских текстов. Все локализованные строки находятся в файлах `data.*.ts` и проверяются интерфейсом `AppData`.

## Терминология и модель данных

В интерфейсе используются принятые фонетические термины:

- инициали;
- переднеязычные, ретрофлексные, альвеоло-палатальные и заднеязычные согласные;
- переднеязычная носовая финаль `-n`;
- заднеязычная носовая финаль `-ng`;
- эризация, или儿化.

Поле `finals` в коде исторически объединяет носовые финали и эризацию. В интерфейсе это отражено названием вкладки «Финали и эризация».

Каждый элемент в `initials` или `finals` имеет следующую структуру:

```ts
{
  id: 'alveolar',
  pinyin: 'd · t · n · l',
  name: 'Альвеолярные',
  marker: { x: 133, y: 138 },
  noContact: false,
  velum: false,
  top: [
    { x: 131, y: 143 }, { x: 172, y: 203 }, { x: 210, y: 249 },
    { x: 252, y: 272 }, { x: 296, y: 287 }, { x: 338, y: 298 }
  ],
  title: 'Кончик языка у альвеолярного валика',
  body: '…',
  example: 'nǐ hǎo → 你好 «привет»'
}
```

Координаты задаются в системе SVG `viewBox="0 0 640 440"`. Массив `top` должен содержать ровно шесть контрольных точек: кончик, переднюю часть, переднюю, среднюю и заднюю части спинки, а также корень языка.

При изменении геометрии одного звука следует проверить соответствующие элементы во всех локалях, чтобы идентификаторы, координаты и положение мягкого нёба оставались согласованными.

## Локальный запуск

Требуется Node.js **^22.22.0 или >=24.8.0**.

```bash
npm install
npm run build
python3 -m http.server 8000
```

После этого откройте:

```text
http://localhost:8000/ru.html
```

Браузеры обычно не загружают ES-модули напрямую через `file://`, поэтому проект следует запускать через локальный HTTP-сервер.

Для непрерывной компиляции во время разработки:

```bash
npx tsc --watch
```

## Тесты

```bash
npm run build
npm run test:unit
npx playwright install --with-deps chromium
npm run test:e2e
npm test
```

Юнит-тесты проверяют геометрию языка, допустимость координат, согласованность языковых данных и ключевые свойства носовых финалей и эризации.

E2E-тесты в Chromium проверяют загрузку страниц, работу всех кнопок, отображение носового воздушного потока и расположение анатомических подписей на разных ширинах экрана.

## Публикация на GitHub Pages

При отправке изменений в `main` workflow `.github/workflows/deploy.yml` выполняет проверку типов, юнит-тесты, сборку и публикацию сайта.

Для первой настройки выберите:

```text
Settings → Pages → Source → GitHub Actions
```

После публикации страницы будут доступны по адресам:

```text
https://<имя-пользователя>.github.io/<репозиторий>/ru.html
https://<имя-пользователя>.github.io/<репозиторий>/en.html
https://<имя-пользователя>.github.io/<репозиторий>/zh-CN.html
```

## Особенности реализации

- Цвет и обводка языка задаются CSS-классом `.tongue-shape`, а не атрибутами SVG. Это предотвращает проблемы с CSS-переменными в некоторых версиях Safari.
- Анатомические подписи разнесены по нескольким уровням и проверяются через `getBBox()`, чтобы они не перекрывались на узких и широких экранах.
- Нижний контур языка рассчитывается относительно верхних контрольных точек. Это предотвращает самопересечение формы в крайних положениях.
